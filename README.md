# Proyecto-Mercadona-
Realización de un proyecto de limpieza y análisis de datos de los Supermercados Mercadona
En la carpeta scripts se encuentran todos los rmds que hemos utilizado para obtener los resultados finales,
el codigo completo se encuentra en proyectoTD, este archivo puede tardar mucho en ejecutar, también hay archivos 
específicos de cada una de las preguntas que contestamos a lo largo del proyecto.
En la carpeta resultados se encuentran los archivos que finalmente presentamos y el analisis de los datos que obtuvimos
tras todo el proceso.
